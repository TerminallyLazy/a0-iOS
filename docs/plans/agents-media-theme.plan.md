# Plan: themed Agents, native media previews and subagent navigation

Status: Gate 1 approved; implementation, package/native verification and independent reviews completed. See ../tdd/agents-media-theme/README.md. Gate 2 approved: the user authorized commit, push, merge and TestFlight release.

## Intended experience

The Agents sheet will carry the selected server theme through its header and bottom safe area. A reply containing a supported direct audio/video link will offer a native Load card while retaining its prose. A compact **Subagents · 2 chats · 1 new** control below the conversation status will make server-reported child chats discoverable; it opens themed cards with their titles and an Open chat action. A child chat offers Return to parent. Existing same-chat agent activity remains available, clearly separate from child chats.

## Verified foundations and limits

- `App/MessageRow.swift` renders `AgentActivitySheet` with a scroll backdrop but omits the existing `ThemeNavigationChrome` modifier used by other sheets. Reuse that modifier before introducing any styling mechanism.
- Ordinary response links currently remain Markdown. Explicit response `a2ui` or Jev candidate payloads use the generated-reply path; the screenshot alone does not prove a media decoder failure.
- Reuse `GeneratedMedia`, `MediaContent`, `MediaDownloads` and embed their Load → player interaction inline, per the approved presentation amendment. This is a narrow **native direct-media preview** exception to the root explicit-A2UI contract, not arbitrary Markdown-to-A2UI conversion.
- The inspected local Agent Zero source revision is `6a6cecff8527b164668c7a6ab2f76b6b1ed7cfa1`; it is not evidence of the phone's live server revision. Its subordinate output metadata includes `parent_context_id`, `parent_agent_number`, `parent_context_kind = subordinate`, `parent_context_label` and `subordinate_slot`. Synced iOS context dictionaries retain metadata that `SpikeModel.ChatSummary` currently omits.
- Subordinate contexts start fresh history and receive only the caller-authored delegated message and attachments; the parent iOS capability suffix is not automatically copied. Parallel subordinate calls use the same path. This can explain ordinary child media links without an explicit A2UI payload, but is not a verified diagnosis of the user's live reply.
- Match only verified subordinate relations between available visible context IDs. Same-context agent numbers do not identify separate chats. Hidden background contexts must not become invented visible chat cards. Older servers without the metadata retain the existing Agents activity experience.
- `running == true` may support a Running badge. False or absent must not mean Completed: synchronous subordinate contexts can lack their own task. Do not infer status from titles, response text or agent-number changes.

Existing media size/track/TLS/DNS/redirect policies remain intact. Synthetic tests prove client behavior; live model generation, live media hosts and physical playback require separate observed acceptance. Gate 1 approval includes the narrow documented direct-media-preview contract extension.
